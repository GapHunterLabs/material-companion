# Material Companion Changelog

## [Unreleased]

## [0.1.0]

### Added

- "Gap Hunter Material" bundled `EditorColorsScheme`: a Material
  Design-inspired dark, high-contrast scheme built on original colors
  drawn from Google's public Material color tokens, applied via the
  `DEFAULT_*` highlighter attribute keys so Java, Kotlin, Python, and
  JS all pick it up without per-language configuration.
- No telemetry, no license prompts, no forced UI changes, no floating
  action buttons.
